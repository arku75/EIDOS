Architecture

One persistent loop, not one giant prompt.

Models may propose or explain. EIDOS is designed to keep state, policy, memory and evidence outside the model and require real-world effects before calling an action successful.

WORLD / COMPUTER ↓ PERCEPTION ↓ MEMORY + KNOWLEDGE GRAPH ↓ COLONY / SPECIALISTS ↓ EIDOS ARBITRATION ↓ PLAN → ACTION / BODY / BRIDGE ↓ OBSERVE REAL EFFECT ↓ VERIFY → LEARN → GENERALIZE → REUSE ↺
Engineering discipline

Evidence before mythology.

Persistent state

Memory, graph state, characters, capability records and policy are intended to survive session and model boundaries.

Observed effects

A successful tool call is not automatically a successful task. The target design compares before/after state and stores the verdict.

Measured learning

Learning counts when persisted changes alter later behavior or measurable outcomes, not merely when more text is stored.

EIDOS is an active research platform in productization. Some capabilities are public and reproducible; others are documented from the live private environment or remain experimental. See the current status boundary before making claims.
