## Public repository capabilities

The repository contains code/documentation for:

- graph and persistent memory;
- Colony/characters;
- Bridge/API;
- Runtime Hub and CLI paths;
- autonomy experiments;
- reversible self-edit experiments;
- Fly/Insect isolated experiments;
- desktop/browser/perception paths;
- tests and GitHub Actions;
- security/constitution/guardian concepts.

Presence in the tree is **not** equivalent to every capability being production-ready.

### Colony / world

- consolidate world-model state with the main causal loop.

## Current maturity statement

A defensible public statement is:

> **EIDOS is an active, source-available local-agent research platform in productization. It already combines persistent memory, graph state, multi-agent deliberation, computer-use interfaces, verification and learning experiments, while several portability, consolidation and end-to-end evidence gates remain open.**

Do **not** describe the complete long-term vision as 100% implemented.

3. README, repository metadata, release notes and landing page agree.
4. One end-to-end demo has a reproducible acceptance test.
5. Security/secret-rotation items are closed or explicitly disclosed.
6. `EIDOS-OFFICIAL` no longer competes as a second source of truth.
