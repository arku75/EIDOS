## Current focus

### EIDOS

[arku75/EIDOS](https://github.com/arku75/EIDOS) is my main research and product project: a local-first persistent agent runtime combining:

- persistent memory and knowledge-graph state;
- multi-agent / Colony deliberation with one arbitration layer;
- browser and desktop computer-use interfaces;
- action-effect verification;
- reusable capability learning;
- local model/tool adapters;
- rollback-oriented self-repair research.

The public repository is intentionally conservative about maturity: experimental mechanisms are separated from verified behavior.
