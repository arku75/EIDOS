# EIDOS Repository Map

This page prevents confusion between repositories with similar names.

## Canonical project

### [arku75/EIDOS](https://github.com/arku75/EIDOS)

**Canonical public repository for Luka Sorta's EIDOS project.**

Use this repository for current documentation, issues, discussions, product evaluation and future releases.

## Legacy / historical

### arku75/EIDOS-OFFICIAL

Historical public surface with stale version labels, counts and loaded claims. It is being converted into a **legacy redirect/archive**, not maintained as a second source of truth.

Do not use it to determine the current architecture or maturity of EIDOS.

## Unrelated project with the same name

### arku75/eidos-encontrado

This repository is a copy/reference of the separate **eidos.space** project (a relational spreadsheet / local data tool). It is **not** Luka Sorta's EIDOS agent runtime and should not be cited as part of this project's codebase or history.

## Other supporting / research repositories

Repositories under the same GitHub account may contain experiments, upstream forks, tooling or references. Their presence does not mean they are official EIDOS components.

A repository is part of the canonical EIDOS public product only when it is explicitly linked from `arku75/EIDOS` and its role is documented.

## Naming rule going forward

- **EIDOS** — canonical project/runtime.
- **EIDOS-OFFICIAL** — legacy/archive only.
- experiments and extracted components should use descriptive names instead of another ambiguous "official" EIDOS repository.
